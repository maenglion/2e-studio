기획 배경과 운영 현황

후다닥 미세먼지 피하기는 9살 기획자 민후가 기존 대기질 앱의 복잡한 정보와 부정확한 위치 표시를 불편해하며 직접 기획한 가족용 대기질 앱입니다. 아이디어, 화면 구성, 필요한 정보와 API 탐색 과정은 Notion에 기록했고, 엄마가 이를 웹 앱, Android 앱과 홈 화면 위젯으로 구현했습니다.

현재 운영 주체는 영리법인인 (주)소울스펙트럼이지만, 이 앱은 수익을 목적으로 하지 않는 무료 가족 프로젝트입니다. 현재 Google Play 비공개 테스트 단계이며 가족 7명이 사용하고 있습니다. 광고, 구독, 유료 결제, 후원 및 데이터 판매는 없습니다.

현재 관측값을 우선 표시하고 예측값은 ‘예측’으로 명확히 구분합니다. WAQI 인제스터는 3시간마다 실행되어 하루 총 8회 데이터를 수집합니다. 앱과 위젯의 안정적인 표시 및 반복적인 외부 API 호출 감소를 위해 최신 관측값을 서버 DB에 임시 저장합니다.

About Hudadak Air

Hudadak Air was conceived by Minhoo, a nine-year-old planner who found existing air-quality apps too complex and their location labels unreliable. The planning process, including the information architecture, screen flow, and API research, is documented in Notion. His mother implemented the idea as a web app, an Android app, and a home-screen widget.

Although the app is operated by Soul Spectrum Co., Ltd., a for-profit company, Hudadak Air is currently a free and non-commercial family project. It is distributed through closed Google Play testing and currently has approximately seven family users. The app has no purchase price, subscriptions, advertising, sponsorship, or data sales.

Current observations are prioritized, while forecast values are clearly identified as predictions. The WAQI ingestion job runs every three hours, for a total of eight scheduled runs per day. The latest observation is temporarily stored in our server database to support reliable app and widget display and to reduce repeated external API requests. WAQI and the original data providers are credited in the app.

현재 서비스 구조

  • 클라이언트: Capacitor 기반 웹·Android 하이브리드 앱
  • 홈 화면: Android 위젯 제공
  • 백엔드: Cloud Run API
  • 데이터 저장: PostgreSQL DB
  • 데이터 표시: 현재 관측값 우선, 모델 예측값은 ‘예측’으로 구분
  • 수집 주기: WAQI 인제스터 3시간마다 실행, 하루 8회
  • 임시 저장: 앱·위젯의 안정적인 제공과 반복 호출 감소를 위해 최신 관측값 저장
  • 운영 상태: 무료·무광고·무구독·무판매, Google Play 비공개 테스트, 가족 7명 사용
